# Ulusal Çaydanlık Meclisi

> "Çay demlenmeden millet uyanmaz."  
> — Birinci Çaydanlık Anayasası, Madde 1 (taslak, henüz referanduma sunulmadı)

Bu depo, çay demleme işlemini **uluslararası standartlara** (yani mutfaktaki teyzenin bakış açısına) göre yöneten resmi protokol yazılımıdır.  
Bilimsel değildir. Daha kötüsü: bilimsel olduğunu iddia eder.

## Neden var?

Çünkü evdeki çaydanlık çoktan fiili bir yasama organı haline geldi. Kaynama sesi gensoru, buhar ise basın açıklamasıdır. Bu yazılım o töreni terminalde tekrarlar. Hiçbir şeyi düzeltmez. Sadece bekletir.

## Kurulum

Python 3 yeter. Çaydanlık zorunlu değildir ama atmosfer için tavsiye edilir.

```bash
python3 meclis.py
```

## Kullanım

Program sizi milletvekili gibi karşılar, suyun ısısını hayal eder, çayı "oylama"ya sunar ve sonunda bir bardak hayali çay ilan eder. Gerçek çay çıkmaz. Hayal kırıklığı çıkar. Bu da bir tür çaydır.

## Mimari

- `meclis.py` — yasama, yürütme ve çay demleme kuvvetleri tek dosyada birleştirilmiştir. Kuvvetler ayrılığı çayın içinde erimiştir.
- Bu README — tüzük, manifesto ve kullanma kılavuzu aynı anda.

## Uyarılar

- Gerçek su kaynatmayın. Yazılım sadece metafor kaynatır.
- Çay şekerli mi şekersiz mi tartışması bu projede bilinçli olarak çözülmemiştir. Çözülürse meclis dağılır.
- Patates yoktur. Asla olmayacaktır.
